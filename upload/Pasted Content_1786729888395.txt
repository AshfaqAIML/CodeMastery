# Master Prompt: Build a Complete Computer Science Tutorial & Learning Platform

Design and develop a **modern, production-ready Computer Science Learning & Tutorial Platform** where users can learn Computer Science, Programming, Data Science, Artificial Intelligence, Machine Learning, Deep Learning, Generative AI, AI Agents, Agentic AI, Software Engineering, and System Design through structured, easy-to-read tutorials.

The platform should feel like a combination of a **Computer Science documentation website, interactive learning platform, personal learning dashboard, and gamified reading application**.

The primary goal is:

> **Help users learn Computer Science from beginner level to advanced level through structured tutorials while motivating them to learn consistently using streaks, points, levels, ranks, achievements, progress tracking, and learning analytics.**

---

# 1. Platform Vision

Create a website where a user can visit and learn almost any major Computer Science topic from a single platform.

The learning journey should be structured from:

**C Programming → C++ → Java → Python → Data Structures → Algorithms → Databases → Operating Systems → Computer Networks → Software Engineering → Web Development → Data Science → Machine Learning → Deep Learning → Computer Vision → NLP → Generative AI → LLMs → AI Agents → Agentic AI → MLOps → Cloud → Distributed Systems → System Design**

The platform should support both:

* Beginners who are starting Computer Science
* Advanced learners preparing for technical interviews, jobs, projects, and professional development

---

# 2. Core Website Concept

Build the platform around five major experiences:

### Learn

Users browse and read structured tutorials.

### Track

Users can see their learning progress, completed tutorials, pages read, subjects completed, streaks, points, levels, and achievements.

### Practice

Users can solve quizzes, coding questions, exercises, and knowledge checks related to tutorials.

### Compete

Users earn points and ranks based on meaningful learning activity.

### Build

Users can use project-based learning paths to apply what they learn.

# 9. Reading Progress Tracking

The platform must track reading progress automatically.

Track:

* Pages opened
* Pages completed
* Tutorials started
* Tutorials completed
* Reading time
* Scroll/read percentage
* Subjects started
* Subjects completed
* Learning paths completed
* Daily activity
* Weekly activity
* Monthly activity

A tutorial should not be counted as completely read simply because the user opens it.

Use meaningful completion logic such as:

* Reading progress reaches a threshold
* User reaches the bottom
* User spends reasonable time on the tutorial
* User optionally marks it complete

Avoid allowing users to easily exploit the points system by repeatedly opening pages.
