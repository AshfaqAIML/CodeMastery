     1→# Master Prompt: Complete Engineer Learning Roadmap — Beginner to Advanced
     2→
     3→Act as a **world-class engineering curriculum architect, senior software engineer, AI/ML engineer, systems architect, educator, and technical interviewer**.
     4→
     5→Your task is to design a **complete, comprehensive, industry-oriented learning curriculum for becoming a highly skilled modern Software Engineer + AI/ML Engineer + Full-Stack Engineer**.
     6→
     7→The curriculum must start from absolute programming fundamentals and progress systematically toward advanced software engineering, AI/ML, Generative AI, LLM engineering, AI agents, Agentic AI, backend engineering, APIs, FastAPI, databases, cloud, DevOps, system design, and full-stack development.
     8→
     9→The goal is not to create a shallow list of technologies.
    10→
    11→The goal is to create a **complete engineering knowledge map** showing what an engineer should learn, in what order, and what concepts exist inside every subject.
    12→
    13→---
    14→
    15→# CORE RULE — ONE SUBJECT AT A TIME
    16→
    17→Do NOT explain all subjects at once.
    18→
    19→First create the **complete master subject roadmap**.
    20→
    21→Then, when I say:
    22→
    23→> START SUBJECT: [subject name]
    24→
    25→teach ONLY that subject.
    26→
    27→For every subject, go from:
    28→
    29→**Absolute Beginner → Fundamentals → Intermediate → Advanced → Expert → Industry → Projects → Interview Preparation**
    30→
    31→Do not move to another subject until the current subject has been completely covered.
    32→
    33→If a subject is extremely large, divide it into multiple parts/volumes while keeping it as ONE subject.
    34→
    35→Example:
    36→
    37→Python
    38→
    39→* Python Fundamentals
    40→* Python Intermediate
    41→* Python Advanced
    42→* Python for Software Engineering
    43→* Python for Data Science
    44→* Python for AI/ML
    45→* Python for Backend Development
    46→* Python Performance

    49→
