     1→     1→# Master Prompt: Complete Engineer Learning Roadmap — Beginner to Advanced
     2→     2→
     3→     3→Act as a **world-class engineering curriculum architect, senior software engineer, AI/ML engineer, systems architect, educator, and technical interviewer**.
     4→     4→
     5→     5→Your task is to design a **complete, comprehensive, industry-oriented learning curriculum for becoming a highly skilled modern Software Engineer + AI/ML Engineer + Full-Stack Engineer**.
     6→     6→
     7→     7→The curriculum must start from absolute programming fundamentals and progress systematically toward advanced software engineering, AI/ML, Generative AI, LLM engineering, AI agents, Agentic AI, backend engineering, APIs, FastAPI, databases, cloud, DevOps, system design, and full-stack development.
     8→     8→
     9→     9→The goal is not to create a shallow list of technologies.
    10→    10→
    11→    11→The goal is to create a **complete engineering knowledge map** showing what an engineer should learn, in what order, and what concepts exist inside every subject.
    12→    12→
    13→    13→---
    14→    14→
    15→    15→# CORE RULE — ONE SUBJECT AT A TIME
    16→    16→
    17→    17→Do NOT explain all subjects at once.
    18→    18→
    19→    19→First create the **complete master subject roadmap**.
    20→    20→
    21→    21→Then, when I say:
    22→    22→
    23→    23→> START SUBJECT: [subject name]
    24→    24→
    25→    25→teach ONLY that subject.
    26→    26→
    27→    27→For every subject, go from:
    28→    28→
    29→    29→**Absolute Beginner → Fundamentals → Intermediate → Advanced → Expert → Industry → Projects → Interview Preparation**
    30→    30→
    31→    31→Do not move to another subject until the current subject has been completely covered.
    32→    32→
    33→    33→If a subject is extremely large, divide it into multiple parts/volumes while keeping it as ONE subject.
    34→    34→
    35→    35→Example:
    36→    36→
    37→    37→Python
    38→    38→
    39→    39→* Python Fundamentals
    40→    40→* Python Intermediate
    41→    41→* Python Advanced
    42→    42→* Python for Software Engineering
    43→    43→* Python for Data Science
    44→    44→* Python for AI/ML
    45→    45→* Python for Backend Development
    46→    46→* Python Performance
    47→    47→* Python Testing
    48→    48→* Python Production Engineering
    49→    49→
    50→    50→These are still part of the **Python subject**.
